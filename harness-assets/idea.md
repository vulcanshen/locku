# locku

終端機的螢幕保護程式加 PIN 鎖。人離開座位時，把正在用的終端機鎖起來：畫面換成一個會動的螢幕保護，任何鍵只會叫出
PIN 輸入框，PIN 對了終端機才回來。不設 PIN 時就是單純的螢幕保護，任何鍵結束。

## 給誰用、在哪裡用

- 整天開著 tmux 或 screen 的人：接成 tmux 的 `lock-command`、screen 的 `LOCKPRG`，prefix 之後一個鍵、或閒置幾分鐘，
  就把離開的那個畫面鎖起來。
- 也可以在裸 tty（例如一條 ssh）直接執行，鎖住那個終端機。
- 只支援 macOS 與 Linux（WSL 可以）；沒有 Windows 版，因為鎖靠的是 tty、pty、`su` 與 tmux / screen。

## 要做什麼

- 鎖定時整個終端機是螢幕保護。七種：LED 點陣板的時鐘、Chrome 離線小恐龍那樣一直跑的 runner、到處反彈的時間框、
  自己玩的貪食蛇、自己玩的俄羅斯方塊、室外的貓，或是使用者自己的程式（例如 `cmatrix -b`）。
- 每種螢幕保護可以存成好幾個有名字的 profile，其中一個是鎖定時用的。
- 有一個設定畫面：設 PIN、管 profile 與每種螢幕保護的預設值、接上 tmux 與 screen，可以先預覽鎖定畫面。
- 接 tmux、screen 時，設定寫在 locku 自己的檔，使用者自己的設定檔只多一行去讀它；關掉時拿得乾乾淨淨。
- 忘記 PIN 時，從自己的 shell 用登入密碼換一組新的。

## 不能發生的事

- 鎖著的時候，除了 PIN 正確、沒設 PIN 時按任意鍵、終端機消失這三種情況，鎖不能結束：`Ctrl-C` 這些只是按鍵，訊號
  一律忽略，當掉了也要重新升起。
- 沒設 PIN、或設定讀不到的時候不能把人鎖在外面：照常顯示螢幕保護、說明原因、任何鍵結束。
- 不擅自改使用者的檔：在使用者打開 `activate` 之前，tmux、screen 與 shell rc 都不寫任何東西；只動 locku 標記的那一段。
- 讀不了的設定或資料不能被預設值蓋掉。
- PIN 不能出現在任何紀錄裡。

## 使用者後來改的

- 2026-11-18：「我想要移除 pin 驗證時輸入錯誤鎖定的 delay 時間，我們讓使用者可以馬上重新輸入」——輸錯一次之後不再等 1 秒，馬上可以重打；連錯幾次之後的冷卻倒數照舊。
- 2026-11-18：什麼都沒打就按 Enter，「空的不算」一次錯。
- 2026-11-18：「新的 saver 是 random，從已經設定好的 profile 中勾選（複選），啟動時隨機從選中的 profile 裡面選一個來進行 lock，如果沒有 profile，就不給新增，所以嚴格意義上，這個新的 saver 沒有自己的東西」

## 刻意不做

- 這不是安全邊界：擋的是誤觸與路人，擋不住同一個帳號的另一條 session。
- 不做 Windows、不用系統密碼驗證（只有 locku 自己的 PIN）、不鎖 Linux 的虛擬主控台、鎖定畫面上沒有「忘記 PIN」的入口。
